    Google's "featured action": examples

    Google has no feature literally called "featured actions". There are two real things:

    1. App link button (appLinkData): exactly 1 per pass, label ≤ 30 chars, no icon (Google marks the logo, title and description as not supported). If an Android app is set it opens the app, otherwise the web link. That's what Badge's "1 Featured Action, ~30 chars, Android package wins" describes: it's Badge's name for this button. Ours is "Open Auto Club app".

    2. Value-added modules (valueAddedModuleData): the ones with your own text and image. If the pass has exactly one, it shows on the front under the hero image. Add more and they all move to a list in the details (up to 15). These screenshots are from Google's docs:

    uri (required) is where a tap goes: a web link or a deep link (our Roadside one uses tel:). sortIndex picks which comes first (lower wins), so with one slot on the front, it decides what members see. viewConstraints.displayInterval sets start/end dates, handy for "Renew now" only near expiry. Modules can live on the class (everyone) or the object (one member).

    Use the switch above the card to see both setups with our AAA modules.

    Featured actions: Apple vs Google

    Google Wallet doesn't have Apple's fixed “Featured Actions”. The closest things are value-added modules (custom tappable cards), the app link button, and the links module in the details. Unlike Apple, you write the text and pick the image yourself.

    How to add a value-added module (JSON) 
    "valueAddedModuleData": [{
  "header": {"defaultValue": {"language": "en-US", "value": "Roadside Assistance"}},
  "body":   {"defaultValue": {"language": "en-US", "value": "Call 24/7 · 1-800-400-4222"}},
  "image":  {"sourceUri": {"uri": "https://…/vam-roadside.jpg"}},
  "uri": "tel:18004004222",
  "sortIndex": 1,
  "viewConstraints": {"displayInterval": {"end": {"date": "2027-03-31T23:59:00-07:00"}}}
}]
    How to add the app link button (JSON) 
    "appLinkData": {
  "androidAppLinkInfo": {"appTarget": {"targetUri": {"uri": "https://play.google.com/…", "description": "AAA app"}}},
  "webAppLinkInfo":     {"appTarget": {"targetUri": {"uri": "https://www.ace.aaa.com/", "description": "Website"}}},
  "displayText": {"defaultValue": {"language": "en-US", "value": "Open Auto Club app"}}
}

    Google marks the per-link title, description and appLogoImage as not supported, and iOS app links aren't supported either.

    How the card is laid out

    Top: round logo + cardTitle. Then subheader (small) and header (big). Then rows from classTemplateInfo.cardTemplateOverride: each row is one, two or three items (Google recommends at most two rows). Then the barcode with its alt text, and the hero image across the bottom.

    Google picks the text color (white or black) from hexBackgroundColor. Everything else (text modules, links, images) goes to the details below the card.
