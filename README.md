# AAA Wallet Pass Viewer

Read-only browser viewer for the AAA `.pkpasstemplate` examples. It shows the front card, the pass details/back fields, the Featured Actions, and the source `pass.json` metadata.

The viewer is intentionally explanatory for design review:

- Apple Wallet chooses Featured Action icons and labels from the supported action type.
- The front layout has limited field positions; values that do not fit remain available on the back.
- The back fields provide the additional service, roadside-assistance, branch, and policy information.

The bundled files are design samples and contain personal-looking test values. Replace them before using this repository for production or broad distribution.
